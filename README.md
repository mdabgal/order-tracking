#  E-Commerce Order Tracking App

An interactive, responsive, and modern Order Tracking Web Application built with **Next.js**, **React**, and **Tailwind CSS**. 

This application allows users to search and track their orders using an Order ID, view live status updates, open an in-app live chat modal with auto-reply support, and directly initiate support calls.

- 🌐 **Live Demo:** [https://order-tracking-orpin.vercel.app](https://order-tracking-orpin.vercel.app)

##  Features

- 🔍 **Real-Time Order Search:** Track orders instantly using unique Order IDs (`ORD-98765`, `ORD-54321`, `ORD-11223`, `ORD-99999`).
- **Dynamic Order Status:** Visual tracking bar showing steps like *Placed*, *Processing*, *Shipped*, and *Delivered*.
-  **Interactive Live Chat:** Built-in pop-up chat modal with quick message options and automatic response system.
-  **Direct Call Support:** One-click button to dial customer support (`tel:+8801700000000`).
-  **Evaluator Switcher (Testing Panel):** Built-in buttons to test different order states quickly during development.
-  **Fully Responsive:** Smooth and optimized user experience across Mobile, Tablet, and Desktop screens.
